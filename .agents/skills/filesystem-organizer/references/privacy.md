# Privacy boundary

Scanning, hashing, relationship analysis, planning, and filesystem copying are local CLI operations.

Metadata read and summarized by the coding agent may enter the agent provider's model context. This includes paths, filenames, timestamps, sizes, Exact Duplicate evidence, Canonical Copy reasons, Structural Relationship evidence, and Skipped Entry Findings. Choosing this agent workflow is consent to that metadata handling; this project does not provide a separate local-only agent mode.

State this boundary before the first CLI command. Never claim that agent-visible metadata remains only on the local machine.
